# 農曆月曆接入紀錄

上方查詢區月曆的每個有效日期格保留原有國曆日號，並依下列規則建立第二行：

- 有二十四節氣時，只顯示既有節氣文字；視覺上不顯示農曆副標題。
- 沒有節氣、且 CWA 農曆資料可查時，顯示 `formatLunarCalendarLabel()` 的簡稱。
- 2022-01-01 至 2050-12-31 以外不建立農曆 span、placeholder 或警告；國曆格、節氣、日期選取與排盤功能不變。

農曆格只以該格的 `year`、`month`、`day` 呼叫 `getLunarDateForSolarDate()`。它不讀取選取時刻、不套用四柱 23:00 換日，也不套用真太陽時。

`src/lunarCalendar.js` 以單一同步 JSON module 載入正式資料，整頁共用，沒有 runtime fetch、CDN 或每格資料請求；因此沒有可個別失敗的非同步農曆載入流程。若靜態資產無法載入，瀏覽器本來就無法載入該 JavaScript module，屬部署完整性問題而非可在單一日期格降級的 runtime 資料錯誤。

ARIA 會在一般日加入完整農曆（例如「農曆六月十五」）；節氣日視覺優先節氣，但 ARIA 同時包含節氣和農曆（例如「2026年8月7日，立秋，農曆六月廿五」）。超出資料範圍不加入農曆 ARIA 文字。

涉及檔案：`src/main.js`、`src/lunarCalendar.js`、`styles/main.css`、`tests/run-tests.js`。測試覆蓋節氣優先、資料範圍、月初與閏月、ARIA、重新渲染結構與原有月曆／排盤回歸。

本包沒有新增春節、元宵、端午、中秋、除夕、吃素日、土地公日、頭尾牙、送接神、鬼門或神明聖誕等民俗日顯示。
