# 農曆資料來源與時間基準

## 用途與範圍

本資料只供上方月曆顯示農曆月日使用；本包不接入 UI。正式農曆支援範圍為 **2022-01-01 至 2050-12-31**。有效但超出此範圍的日期不顯示農曆，國曆、節氣、四柱、九宮飛星、金函玉鏡與奇門遁甲功能仍各自依原有規則運作。

唯一正式來源是交通部中央氣象署（CWA）「日曆資料」，資料集 ID `157677` 的資源 `A-A0087-001`「國農曆日期對照」。資料集公開列出的欄位為：日期、民國年、農曆年、農曆月、農曆日、星期，授權方式為政府資料開放授權條款－第 1 版。

- 資料集頁：https://data.gov.tw/dataset/157677
- 資源下載 URL：https://opendata.cwa.gov.tw/fileapi/v1/opendataapi/A-A0087-001?Authorization=rdec-key-123-45678-011121314&format=CSV
- CWA 使用規範：https://opendata.cwa.gov.tw/about/rules
- 原始檔取得時間：2026-08-03T05:39:11.801Z
- 原始檔 SHA-256：`1977895ede93d8cac33355fa5d51cd021f384c1298e46c075b81d8be99d576be`

完整取得與生成資訊在 `data/cwa_lunar_calendar_manifest_2022_2050.json`；逐日還原驗證在 `data/cwa_lunar_calendar_validation_2022_2050.json`。原始 CSV 不納入本 repository，避免重複散布完整原始檔；使用者可依 manifest 的 URL、SHA-256 與 `scripts/build-cwa-lunar-calendar-data.js` 重建衍生資料。

## CWA 回覆的技術性摘要

本包依中央氣象署已回覆並由本工作規格提供的技術摘要採用下列民用農曆契約：

- 時間基準為臺灣標準時間 UTC+8，以午夜 00:00 作民用日期分界。
- 農曆初一由天文計算的朔換算為臺灣標準時間後所落的公曆日期決定。
- 臺灣各縣市經度及地方真太陽時不改變民用農曆日期；命理排盤的真太陽時是另一層邏輯。
- 曆法推算依據美國海軍天文臺 MICA 軟體。
- 歷史國農曆對照原則上依當時臺灣實際法定標準時間。
- `A-A0087-001` 會隨新國民曆編算不定期增加年度；本專案不自行推算，也不以任何第三方資料補足 2051 年以後。

本 package 所提供的 CWA 回覆摘要沒有回覆日期，且研究目錄未保存原信；因此本文件不臆測日期，也不公開任何個人聯絡資訊。日後若可提供可公開的回覆日期，可在不改變上述技術內容下補記。

## 壓縮格式與邊界

正式 runtime 檔為 `data/cwa_lunar_month_starts_2022_2050.json`。它以每個可完整驗證月的月首保存 `solarStart`、`lunarYear`、`lunarMonth`、`isLeapMonth` 與由相鄰月首推得的 `monthLength`（僅 29 或 30）。

2022-01-01 落在 CSV 起點之前已開始的農曆十一月，2050-12-31 落在 CSV 終點後仍未結束的農曆十一月。為避免補算範圍外月首，檔案使用兩段最小、已由 CWA 日表直接驗證的邊界資料：前端 2 日與尾端 18 日。這是 month-start + boundary segments 的 hybrid 格式，不推論 2021 或 2051 的任何日子。

生成驗證確定 10,592 筆 CWA 日資料均可還原，mismatch、missing、duplicate 和 invalid month length 均為 0。資料很小（pretty JSON 53,175 bytes、minified 35,157 bytes、gzip 3,185 bytes），適合一次隨 helper 的 JSON module 載入，不需拆年度檔或執行時遠端請求。

## 明確不採用來源

本功能不使用香港天文台資料、`solarlunar`、`lunar-javascript`、`chinese-lunar` 或其他第三方農曆套件；不使用 CDN、遠端 runtime API、無來源位元表，也不自行計算朔、閏月或範圍外日期。
