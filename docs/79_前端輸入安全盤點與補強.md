# 前端輸入安全盤點與補強

## 範圍與 threat model

本專案是 static browser app；使用者輸入只在瀏覽器內進行日期、時區、座標與排盤計算，不假設有可信的遠端輸入或後端 session。

## 8B-SEC-A audit 結論

- 未發現真正 user input 進入 dangerous DOM/code sink 的路徑。
- UI 輸出維持 `textContent`、`createElement` 與 `replaceChildren`。
- 沒有 `innerHTML`、`insertAdjacentHTML`、`document.write`、runtime `eval` 或 runtime `Function`。
- geolocation 只在使用者按鈕後取得，座標留在瀏覽器本地，不上傳。
- 沒有 localStorage、sessionStorage、cookie persistence 或 indexedDB。
- production fetch 僅限同源靜態 JSON；沒有 user-input upload path。

## 本包的最小補強

- 座標輸入以 HTML `maxlength=128` 與 parser early guard 限制長度；超長、NaN、Infinity、RTL 或 zero-width 異常值直接視為 invalid。
- IANA 時區輸入以 HTML `maxlength=128`、search/validation early guard 限制長度；搜尋使用 200ms 一次性 debounce，Enter、鍵盤選取與 change 仍立即完成最終驗證。
- invalid timezone 不加入 cache；有效 formatter cache 與真太陽時 offset cache 都維持 bounded 128 entries。
- `datetime-local` 與自訂日期／時間 parser 拒絕超過 32 字元的 malformed input，不改變正常日期時間語意。

## token-like metadata

舊 commit 曾含 token-like source metadata；repo 無法僅由內容判定其是否為有效 credential，分類為 **cannot determine**。現行 working tree 已移除 credential-like query，保留 CWA dataset／resource identification；沒有重寫 Git history，也沒有呼叫 CWA API 驗證。

## CSP 與 residual risk

CSP 可作為 defense-in-depth，待整個 UI/runtime 穩定後再決定；本包不修改 deployment。剩餘風險是歷史 commit 仍可被 repository 讀取，以及瀏覽器／依賴自身的未來變更，應由 repository owner 另行處理。
